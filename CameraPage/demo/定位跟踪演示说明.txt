================================================================================
  定位跟踪演示 - 方案说明与操作指南
================================================================================

一、整体思路（给演示准备人员）
--------------------------------------------------------------------------------

  主板存储有限，无法实时存长视频。演示采用「离线处理 + 前端播放」：

  ┌─────────────┐     帧差/插帧      ┌──────────────┐     裁剪保存     ┌────────────┐
  │ 相机原始帧   │ ───────────────► │ 检测框+定位点  │ ──────────────► │ 短 MP4 片段 │
  │ (两路相机)   │     (主板离线)    │ 叠加到画面上   │   ≤1分钟总量    │ 放 demo/clips│
  └─────────────┘                   └──────────────┘                 └──────┬─────┘
                                                                              │
                                                                              ▼
                                                                    ┌─────────────────┐
                                                                    │ 管理平台网页播放  │
                                                                    │ 定位跟踪模块      │
                                                                    └─────────────────┘

  本次演示剧本：
    · 一号相机（入口枪机）：0 ~ 10 秒，目标首次出现 → cam1_track.mp4
    · 二号相机（大厅枪机）：30 ~ 45 秒，目标再次出现 → cam2_track.mp4
    · 前端按时间轴连续播放两段，右侧列表同步显示定位坐标，模拟跨相机跟踪


二、主板侧你要做的事（非网页代码）
--------------------------------------------------------------------------------

  1. 从两路相机各采集一段原始帧（或短视频），总长不超过 60 秒
  2. 相邻帧做差分，变化区域标注为「人」检测框
  3. 框中心作为定位点，按时间顺序写入轨迹（同一目标 ID 保持一致，如 1024）
  4. 将框和点画到画面上，导出两段 MP4：
       demo/clips/cam1_track.mp4   （0~10 秒）
       demo/clips/cam2_track.mp4   （30~45 秒）
  5. （可选）把每段关键帧坐标写入 demo/demo-manifest.json 的 tracks.keyframes
     → 即使视频未拷入，网页也能用画布回放坐标轨迹


三、前端网页已做好的功能
--------------------------------------------------------------------------------

  模块位置：左侧导航 → 定位跟踪

  界面组成：
    · 视频预览区：播放预存定位视频（有 MP4 播视频，无 MP4 用画布按坐标回放）
    · 演示时间轴：可视化 0~10s 与 30~45s 两段
    · 播放按钮：开始演示（连续）/ 一号相机 / 二号相机
    · 目标定位列表：随播放时间更新 ID 与中心坐标
    · 获取定位视频：展示两段已保存文件路径，供复制

  配置文件：demo/demo-manifest.json
    · 修改设备名称、时间段、视频路径、关键帧坐标均在此文件


四、演示当天操作流程
--------------------------------------------------------------------------------

  1. 将 cam1_track.mp4、cam2_track.mp4 放入 demo/clips/
  2. Ubuntu 虚拟机启动：bash deploy/start-server.sh
  3. Windows 浏览器打开平台 → 定位跟踪
  4. 点击「开始演示」→ 先播一号相机 10 秒，自动切二号相机 15 秒
  5. 点击「获取定位视频」→ 向客户展示两段已保存的定位视频路径
  6. 讲解：目标在 0~10s 于入口相机出现，30~45s 于大厅相机再次出现，实现跟踪关联


五、文件清单
--------------------------------------------------------------------------------

  demo/demo-manifest.json      演示配置（时间段、坐标、视频路径）
  demo/clips/cam1_track.mp4    一号相机定位视频（需自行生成）
  demo/clips/cam2_track.mp4    二号相机定位视频（需自行生成）
  js/tracking-demo.js          演示播放逻辑
  index.html                   定位跟踪页面 UI
