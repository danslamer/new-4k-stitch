一、项目说明
--------------------------------------------------------------------------------
  本平台为 B/S（Browser/Server，浏览器/服务器）架构的前端演示原型。
  面向边缘智能相机及嵌入式视频设备，提供统一管理界面。

  四大功能模块：
    · 图像输出   — 视频预览、码流配置、算法结果展示、RTSP 输出
    · 网络配置   — TCP/IP 参数、网络监测、Ping 诊断
    · 算法管理   — 六路算法槽位，启用/停用及效果预览
    · 设备管理   — 本机与外部设备台账，切换预览源

  说明：当前为静态页面 + 模拟数据，未接入真实相机与后端 API。


二、目录结构
--------------------------------------------------------------------------------
  相机页面/
  ├── index.html              主页面（四大模块入口）
  ├── css/
  │   └── style.css           界面样式
  ├── js/
  │   └── app.js              交互逻辑与模拟数据
  ├── deploy/
  │   ├── start-server.sh     Ubuntu 虚拟机启动 B/S 服务端（推荐）
  │   └── open-from-host.bat  Windows 主机一键检测并打开浏览器
  └── 使用说明.txt            本文件


三、演示环境要求
--------------------------------------------------------------------------------
  · 虚拟机：VMware + Ubuntu 22.04.5 LTS（模拟嵌入式主板）
  · 主机：  Windows，安装浏览器（Chrome / Edge 等）
  · 网络：  虚拟机网卡设置为【桥接模式】（推荐）
  · 依赖：  Ubuntu 自带 python3，无需额外安装


四、操作流程（推荐：桥接模式）
--------------------------------------------------------------------------------

  【步骤 1】配置虚拟机网络
    1. 打开 VMware → 虚拟机设置 → 网络适配器
    2. 选择「桥接模式：直接连接物理网络」
    3. 勾选「已连接」「启动时连接」
    4. 启动 Ubuntu 虚拟机

  【步骤 2】查看虚拟机 IP
    在 Ubuntu 终端执行：
      hostname -I
    记下第一个 IP，例如：192.168.110.124

  【步骤 3】启动 B/S 服务端（Ubuntu 虚拟机内）
    进入项目目录，例如：
      cd ~/桌面/相机页面

    首次使用需赋予脚本执行权限：
      chmod +x deploy/start-server.sh

    启动服务：
      bash deploy/start-server.sh

    看到以下信息表示成功：
      Serving HTTP on 0.0.0.0 port 8080 ...
    终端会同时打印主机访问地址，例如：
      http://192.168.110.124:8080/index.html

    注意：此终端需保持运行，关闭或 Ctrl+C 即停止服务。

  【步骤 4】Windows 主机浏览器访问（客户端）
    方式 A — 手动打开浏览器，地址栏输入：
      http://<虚拟机IP>:8080/index.html
      示例：http://192.168.110.124:8080/index.html

    方式 B — 双击运行（在项目 deploy 目录下）：
      open-from-host.bat
      按提示输入虚拟机 IP，脚本会自动检测连通性并打开浏览器。

  【步骤 5】演示操作
    · 请在 Windows 主机浏览器中操作，不要在 Ubuntu 虚拟机内打开页面
    · 左侧导航切换四个功能模块
    · 设备管理 → 点击「预览」可切换图像输出页面的视频源
    · 算法管理 → 启用算法后，首页「上传算法」区域会显示文字结果

  【步骤 6】停止服务
    在 Ubuntu 运行 start-server.sh 的终端中按：Ctrl + C

六、常见问题
--------------------------------------------------------------------------------
  Q1：Windows 浏览器打不开页面？
    · 确认 Ubuntu 中服务已启动（步骤 3）
    · 确认虚拟机为桥接模式，IP 与主机在同一网段
    · 在 Ubuntu 执行 hostname -I 核对 IP 是否变化（DHCP 可能重新分配）
    · 检查 Windows 防火墙是否拦截（可先临时关闭测试）

  Q2：NAT 模式能否访问？
    · 可以，但需在 VMware 中配置端口转发（主机 8080 → 虚拟机 8080）
    · 桥接模式更简单，演示推荐使用桥接

  Q3：修改代码后如何生效？
    · 保存 html / css / js 文件后，在浏览器按 Ctrl + F5 强制刷新即可
    · 无需重启 python 服务（静态文件直接读取）

  Q4：界面数据是真实的吗？
    · 否。码率、网络监测、算法结果等均为前端模拟数据，用于界面演示。
